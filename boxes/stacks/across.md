# across: one box over every repository, each answering in turn

Run by `lay.py --across` over the box laid from every repository's list
and mirrors at once. fair-merge ranks each source on its own, from its index, and takes
turns, so cpython's thousands of files can't crowd out the Provider's
eighty. These are the questions that cross repositories: where one leans
on another, and where two solve the same thing.

## where one repository leans on another
- fair-merge -- {indexes} "how does the provider call willow"
- fair-merge -- {indexes} "how is the willow pin moved"
- fair-merge -- {indexes} "how does pyperformance build cpython"
- fair-merge -- {indexes} "how is the code graph read from sqlite"

## the same thing, solved in each
- fair-merge -- {indexes} "what never leaves the machine"
- fair-merge -- {indexes} "how is a secret kept out of a page"
- fair-merge -- {indexes} "how is a hook allowed to block a tool"
- fair-merge -- {indexes} "how are tests split to run in parallel"
